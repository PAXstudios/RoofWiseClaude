# RoofWise display fonts

`BarlowCondensed-BlackItalic.ttf` is registered as `RoofWiseDisplay`.
`BarlowCondensed-Bold.ttf` is registered as `RoofWiseHeading`.

Source: https://github.com/google/fonts/tree/main/ofl/barlowcondensed

Copyright 2017 The Barlow Project Authors. Distributed under the SIL Open Font
License included in `OFL.txt`. The existing Archivo package remains the body and
control font. Both local files load behind the existing splash gate, so no font
request is required at runtime.
